# AJcreativesPortfolio

A highly polished, premium interactive portfolio for **AJcreatives** specializing in creative post-production, branding, and motion design.

## Features
- **Dynamic 3D Spline Layers:** Two layered interactive Spline scenes (volumetric light rays and text-distorting canvas) rendering simultaneously.
- **Client Endorsements:** Sourced directly from YTJobs with high-res channel logos.
- **Infinite Scrolling Marquee:** Native GPU-accelerated comments carousel that pauses on hover.
- **Cinematic Pacing:** Integration of custom videos and responsive layouts using Tailwind CDN and Lenis smooth scrolling.
